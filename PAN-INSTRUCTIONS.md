# Instruções de Navegação no Canvas

## ✅ Problemas Corrigidos

1. **Grid única** - Removida a segunda grid duplicada. Agora há apenas uma grid fixa no canvas.
2. **Scrollbars removidos** - O canvas não mostra mais barras de rolagem.
3. **Zoom pelo mouse removido** - O scroll do mouse não faz mais zoom.

## 🖱️ Como Navegar pelo Canvas

Para ver todo o mapa sem scrollbars, você pode usar **PAN (arrastar)**:

### Opção 1: Tecla Space + Clique
1. Segure a tecla **ESPAÇO (Space)**
2. Clique e arraste com o botão esquerdo do mouse
3. O cursor mudará para 🤚 (mão) mostrando que você pode arrastar

### Opção 2: Botão Direito do Mouse
1. Clique e arraste com o **botão direito** do mouse
2. Funciona sem pressionar nenhuma tecla

### Opção 3: Botão do Meio do Mouse
1. Clique e arraste com o **botão do meio** (scroll wheel como botão)
2. Funciona sem pressionar nenhuma tecla

### 📱 No Mobile/Touch
- Arraste com **um dedo** para mover a visualização

## 🎯 Interagindo com Items

- **Clique normal** (sem Space): seleciona e arrasta items
- **Space + Clique**: move a visualização do canvas (não arrasta items)

Dessa forma você pode ver todo o conteúdo do canvas arrastando a visualização!
